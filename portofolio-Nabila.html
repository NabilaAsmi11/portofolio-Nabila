Tentang Saya

Saya Nabila Putri Asmi, mahasiswa Program Studi D3 Sistem Informasi, Jurusan Teknologi Informasi, Politeknik Negeri Padang. Saya memiliki ketertarikan pada pengembangan web, Web Design, UI/UX, dan pengembangan aplikasi menggunakan Flutter.

Melalui berbagai proyek perkuliahan dan latihan mandiri, saya terus mengembangkan keterampilan dalam membangun website, merancang antarmuka pengguna menggunakan Figma, serta menciptakan desain aplikasi yang menarik, fungsional, dan mudah digunakan. Saya juga memiliki minat untuk memperdalam pengembangan web menggunakan Laravel.

Saya ingin mengikuti program magang untuk menerapkan ilmu yang telah dipelajari, memperoleh pengalaman langsung di dunia industri, serta meningkatkan kemampuan teknis dan profesional. Dengan semangat belajar, kreativitas, dan kemauan untuk terus berkembang, saya siap berkontribusi dalam tim sekaligus memberikan hasil kerja yang bermanfaat bagi perusahaan.
